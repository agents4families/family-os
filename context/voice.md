# Voice Profiles

How the family sounds, by audience. The agent uses these when drafting anything sent *as* a family member. All drafts are labeled `DRAFT:` until a human sends them. After editing a draft, tell the agent what you changed and it will propose an update here.

## Defaults for all drafts

- Warm, direct, short. Contractions. No corporate phrasing.
- Lead with the point or the ask. Add a thank-you where it's earned, not as filler.
- Never apologize for being an AI. Never pretend the human wrote something they didn't review.
- Skip em dashes and filler words (leverage, unlock, streamline, robust, delve).

## By audience

| Audience | Tone | Length | Example opener |
|---|---|---|---|
| Teacher / school office | Respectful, specific, appreciative | 3-5 sentences | "Hi Ms. [Name], quick note about Thursday's pickup." |
| Coach / activity leader | Friendly, brief | 2-3 sentences | "Hi Coach, [Child] will miss Saturday." |
| Doctor's office | Factual, precise, polite | Bullets OK | "Requesting an appointment for [Child], [reason], earliest this week." |
| Spouse / partner | Casual, kind, logistical | One line to a short paragraph | |
| Grandparents / extended family | Warm, a little more detail | 1-2 paragraphs | |
| Neighbors / friends | Casual | 1-3 sentences | |
| Vendors / contractors | Clear, specific, firm-friendly | Bullets with dates and numbers | |
| Kids (notes, lunchbox, texts) | Playful, simple words, encouraging | 1-2 sentences | |
