# Decision Log

One file per significant family decision, named `YYYY-MM-DD-short-name.md`. Written by the `decision-brief` skill after the adults decide, then approved and moved here. The point: nobody re-litigates a settled decision, and new information has a place to land.

Template:

```markdown
---
decision: <short name>
date: YYYY-MM-DD
deciders: <adults>
status: decided | revisit-by YYYY-MM-DD | reversed
sensitivity: 0-2
---
# <Decision>

**Context:** <why this came up, 2-3 lines>
**Options considered:** <A, B, C with one-line cost/benefit each>
**Decision:** <what we chose>
**Why:** <the 2-3 reasons that actually decided it>
**What would change our mind:** <specific trigger>
**Owner and next step:** <name, date>
**Kids' view (if relevant):** <what we told them / what they said>
```
